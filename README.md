# 🌍 Análisis de Datos Climáticos - UTN TUP 2026

## 📌 Descripción
Este proyecto realiza un análisis básico de datos climáticos utilizando Python.  
Se busca calcular métricas simples como promedio, máximos y mínimos de temperatura.

---

## 🛠️ Tecnologías utilizadas
- Python
- Google Colab
- Git / GitHub
- Jira (gestión de tareas)

---

## 📊 Funcionalidad
El script permite:
- Procesar un conjunto de temperaturas
- Calcular indicadores básicos
- Generar una conclusión automática simple

---

## 🚀 Cómo ejecutar el proyecto

### Opción 1: Google Colab
1. Abrir Google Colab
2. Copiar el archivo `analisis_climatico.py`
3. Ejecutar todas las celdas
